# Source dialogue before silent closing

The restricted-plan guidance now makes the phone generator responsible for any
source-required concluding speech. A compiled `close_call` ends silently; it does
not supply farewell, customer-channel advice or explanatory dialogue. Applicable
normal, early-exit and handoff paths must place that speech before the guarded
close. Claims about recorded actions still need the approved runtime evidence;
the plan cannot announce a successful final close before the API returns.

When the frozen policy requires a shared deadline or corrections across products,
the authored dialogue must explain the adjustment and obtain renewed agreement
before commitment and closing. The reference introduces no default deadline,
calendar, advice, farewell, product type or bank-specific phrase. Guards continue
to calculate and enforce terms and consent; their existence does not prove that
the required explanation was spoken.

Both the extraction and transport references document the already supported conditional
`account_disclosure_fields` object: `common` fields apply to every product, and
`by_product_type` fields apply only to the selected source/API type. Legacy arrays
remain mandatory for every product. Use only the compiled approved displays for
narration; missing required fields block disclosure and unrelated API extras
remain private. Protected state and the complete `bg_facts` object are never TTS.
Extraction must not flatten type-limited fields into the unconditional array;
other unsupported conditions remain explicit instead of widening permission.

The dedicated regressions check the approved-input policy prompt against its typed
interface, active amendment transport without historical
text, absence of invented advice or values, and exact compiled ordering of an
independently authored speaking route before silent termination. They also show
that a frozen speech rule alone does not make the compiler speak it. These use
synthetic inputs, ideal extraction frames and mock receipts without model,
network or hosted execution. They establish source transport and graph behavior;
actual generated speech compliance remains an evaluation requirement. Existing
generated artifacts are unchanged and require fresh generation to use guidance.
